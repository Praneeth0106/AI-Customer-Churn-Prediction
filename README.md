# AI-Powered Customer Churn Prediction and Data Analytics

## Project Overview
This project analyzes telecom customer data to understand customer churn and predict which customers are likely to leave a telecom service.

The project combines Python, SQL, Machine Learning, and Power BI to generate business insights and support customer retention strategies.

## Objectives
- Analyze customer churn patterns.
- Identify factors that influence customer churn.
- Perform business analysis using SQL.
- Build machine learning models to predict customer churn.
- Create an interactive Power BI dashboard.

## Tools and Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- MySQL
- Power BI
- Google Colab

## Dataset
IBM Telco Customer Churn dataset.

- Total customer records: 7,043
- Target variable: Churn
- Dataset contains customer information, services, contract details and billing information.

## Project Workflow

1. Data Collection – Loaded the IBM Telco Customer Churn dataset.
2. Data Cleaning – Handled missing values, converted data types and removed duplicates using Python.
3. Exploratory Data Analysis – Analyzed churn patterns using charts and visualizations.
4. SQL Analysis – Performed customer and business analysis using MySQL.
5. Machine Learning – Trained and evaluated Logistic Regression and Random Forest models.
6. Power BI Dashboard – Created KPI cards, churn analysis charts and interactive slicers.

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

Models were evaluated using accuracy, precision, recall, F1-score, confusion matrix and ROC-AUC.

## Power BI Dashboard
The dashboard includes:
- Total Customers
- Churned Customers
- Retained Customers
- Overall Churn Rate
- Churn by Contract Type
- Churn by Payment Method
- Churn by Tenure Group
- Churn by Internet Service
- Interactive filters

## Key Business Insight
The overall customer churn rate in the dataset is approximately 26.54%.

Month-to-month contracts and shorter customer tenure show higher churn rates in the analysis.

## Project Outcome
This project demonstrates how data analytics and machine learning can be used to understand customer behavior, identify churn patterns and support customer retention decisions.
